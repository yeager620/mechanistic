MLP Reconstruction Module Implementation Plan

  Overview

  Create a self-contained module to reconstruct all 24 trained Multi-Layer Perceptrons (MLPs) from Microsoft's Phi-2 model, storing them in a format suitable for later approximation.

  Architecture Specifications

  Phi-2 MLP Architecture

  - Total MLPs: 24 (one per transformer layer)
  - Architecture: MLP(x) = W2(GELU(W1*x + b1)) + b2
  - Dimensions: 2048 → 8192 → 2048
  - Activation: GELU ("gelu_new" variant)
  - Parameters per MLP:
    - FC1: weights (8192, 2048) + bias (8192,)
    - FC2: weights (2048, 8192) + bias (2048,)

  Current vs Target Schema

  # Current (weights only)
  FF1_0 to FF1_23: (8192, 2048)  # fc1 weights
  FF2_0 to FF2_23: (2048, 8192)  # fc2 weights

  # Target (weights + biases)
  FF1_0 to FF1_23: (8192, 2048)        # fc1 weights
  FF2_0 to FF2_23: (2048, 8192)        # fc2 weights  
  FF1_bias_0 to FF1_bias_23: (8192,)   # fc1 biases
  FF2_bias_0 to FF2_bias_23: (2048,)   # fc2 biases

  Compatibility Guarantees

  ✅ No Interference With:

  - Data Loading: Bias terms use distinct naming patterns
  - TDA Processing: Operates on existing weight matrices only
  - Remote Workflows: HuggingFace streaming unchanged
  - Existing CLI: All current commands work identically

  ✅ Backward Compatibility:

  - Existing weight extraction preserves all current functionality
  - New bias extraction is purely additive
  - Documentation fixes are cosmetic corrections

  Success Criteria

  1. Completeness: All 24 MLPs reconstructed with weights + biases
  2. Accuracy: Numerical outputs match original model within 1e-6 tolerance
  3. Usability: MLPs saved in PyTorch format ready for approximation
  4. Compatibility: No disruption to existing TDA workflows
  5. Documentation: Corrected architectural specifications throughout
